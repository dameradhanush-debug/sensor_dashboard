E-Commerce Website Architecture

1. Frontend

The frontend is the part of the website that users see and interact with.

Technologies Used

  • HTML
  • CSS
  • JavaScript

Examples

  • Home Page
  • Product Page
  • Shopping Cart
  • Checkout Page

2. Backend

The backend handles the business logic and processes requests from users.

Technologies Used

  • Node.js
  • Express.js

Functions

  • User Authentication
  • Product Management
  • Order Processing
  • Payment Processing

3. Database

The database stores all important information of the application.

Database Examples

  • MySQL
  • MongoDB
  • PostgreSQL

Stored Data

  • Users
  • Products
  • Orders
  • Payments

Architecture Flow

USER

↓

FRONTEND

↓

BACKEND
