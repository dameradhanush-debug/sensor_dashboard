Full-Stack Web Architecture

1. Frontend

The frontend is responsible for displaying information to the user.

Technologies: HTML, CSS and JavaScript.

2. Backend

The backend receives requests, processes data and sends responses.

Example: Node.js and Express.js.

3. Database

The database stores application data.

Examples: MySQL, MongoDB and PostgreSQL.
